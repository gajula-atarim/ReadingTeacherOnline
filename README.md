# Reading Teacher Online – homepage build

Working repo for the initial homepage on https://readingteacheronline.wsdfy.com (Elementor + Hello Elementor child).

- `design/original/` – unmodified homepage design files from the supplied brand-kit ZIP (approved design: `Reading Teacher 3.dc.html`). Client intake uploads and macOS metadata are not included.
- `design/optimised/` – resized/compressed WebP versions of the assets used on the homepage.
- `build/` – generated Elementor data, child-theme CSS/JS and scripts used to build the page.
